# HomeWise AI — Project Ground Rules

These engineering ground rules were established at project start and govern
all phases of work.

1. Work only on the specific task requested.
2. Do not implement multiple development phases at once.
3. Before making significant changes, explain the proposed approach.
4. Never assume an API, model capability, package, or configuration exists
   without verifying it.
5. Use official Meta documentation for Meta Model API integration.
6. Prioritize secure coding practices.
7. Never expose, print, or log API keys, credentials, or populated
   environment variables.
8. Never modify or delete unrelated files.
9. Never introduce unnecessary dependencies or infrastructure.
10. Financial calculations must be deterministic application logic,
    not LLM-generated arithmetic.
11. All user inputs and model outputs must be validated.
12. Write tests for important functionality.
13. Do not claim something works unless it has actually been tested.
14. Explain important technical decisions in understandable language.
15. At the end of each task, report files changed, commands executed,
    tests performed, and outstanding issues.
